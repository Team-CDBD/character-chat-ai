# 캐릭터 챗 AI 검수 후 수정 기록

작업일은 2026-11-28이며 기준 커밋은 `40068cc`다.

|---|---|---|
| 워커 중단과 기억 재처리 | 기억 반영 순번이 이미 진행된 작업도 다시 가져온다. 저장된 기억에서 미색인 항목을 읽어 임베딩과 요약을 이어가고, 앞선 작업이 끝날 때까지 같은 대화의 다음 기억 작업을 보류한다. | 첫 턴의 저장 직후 워커를 중단하고 lease를 만료시켰다. 두 작업 모두 완료됐으며 첫 턴 추출 비용 기록은 한 건이었다. |

## 검증 결과

Python 3.12, PostgreSQL 16.2, pgvector 0.6.2, MockProvider로 확인했다. 독립 테스트 DB에 Alembic 마이그레이션을 적용했다.

- 수정 전 테스트 53개 통과
- 수정 후 `pytest -q` 60개 통과, 건너뛴 테스트 0개
- `ruff check .` 및 `python -m tools.export_contracts --check` 통과

## 배포와 적용 범위

애플리케이션과 워커를 갱신할 때 Alembic 0002를 적용한다. 기존 APPLIED·FAILED 이벤트 원문을 지우므로 다운그레이드로 해당 내용을 복원할 수 없다. 기존 순번·영수증은 유지된다. 실제 서비스 DB에는 적용하지 않았다.

캐릭터 설정 편집 시 캐릭터 주체의 옛 기억을 보수적으로 제외하므로 내용이 여전히 유효한 기억도 검색에서 빠질 수 있다. 최근 대화 원문과 요약에는 당시의 설정이 등장할 수 있다. 선호 검사는 직접적인 한국어 표현을 다루며 일반적인 의미 일치 판정과 실모델 대화 품질 평가는 별도 과제다.
